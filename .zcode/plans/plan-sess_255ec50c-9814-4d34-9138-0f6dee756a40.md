# خطوط سفلية ملوّنة حسب نوع خطأ التسميع

## الخلفية والقرارات المعتمدة

بما أن خطوط QCF ملونة داخليًا (COLR) ولا تستجيب لـ `TextStyle.color`، فإن **الخط السفلي (`TextDecoration.underline`) يرسمه محرك النص وليس الخط** — فيعمل مؤكدًا وهو الطريق الوحيد العملي للتمييز البصري. القرارات: صحيح = خط أخضر، الخطأ = خط بلون نوعه (تجويد بنفسجي / نطق أحمر / تشكيل برتقالي)، تصنيف **حيّ لحظي** أثناء التلاوة عبر توسعة المتتبّع، والتقييم النهائي بعد الإيقاف يبقى المرجع ويصحّح التصنيف. الألوان كلها قابلة للتجاوز من `TasmeeStyle`.

## 1) نوع الخطأ كنوع جديد في المحرك

- **ملف جديد `engine/tasmee_error_kind.dart`**: ‏`enum TasmeeErrorKind { correct, normal, tashkeel, tajweed }` + محوّل من نص `errorType` النهائي + دالة أسبقية الدمج (تجويد > نطق > تشكيل). يُصدَّر من البرميل.
- **`range_tracker.dart`** (القلب):
  - توقيع `onWordDone(verseIdx, wordIdx, TasmeeErrorKind kind)` بدل bool — `correct` = سليم.
  - `_erroredSpans` (مجموعة بلا نوع) تصبح `Map<QuranRangeWordSpan, TasmeeErrorKind>` بدمج بالأسبقية.
  - التصنيف عند الاستهلاك: رمز مطابق تمامًا = سليم؛ نفس الحرف برمز مختلف = تصنيف الفروق (مدّ/شدة/قلقلة/غنّة/إخفاء = **تجويد**، وإلا فرق حركة = **تشكيل**) — نفس منطق `error_detector`؛ وحدات متخطَّاة (حذف) = التجويدية منها **تجويد** وعادية **نطق**؛ إدراج زائد = **نطق**. تقدّم المؤشر نفسه لا يتغير إطلاقًا (مخاطرة صفرية على الإصلاح الأخير).
- **`recitation_session.dart` + `live_recitation_engine.dart` + `sherpa_zipformer_engine.dart`**: تحديث نوع الحقل/المعامل فقط (تمرير عبر).

## 2) الحالة والمتحكم

- **`tasmee_state.dart`**: خريطة جديدة `RxMap<String, TasmeeErrorKind> wordErrorKinds` بنفس مفتاح الحالات `'$ayahUq:$wordNumber'`.
- **`tasmee_ctrl.dart`**: `_onWordDone` يخزن الحالة (صحيح/خطأ) والنوع معًا؛ `_applyFinalErrorsToStatuses` يرقّع الأنواع من `error.errorType` النهائي (بأسبقية الدمج عند تعدد الأخطاء في كلمة)؛ مسح الخريطة في retry/exit/إعادة بناء النطاق؛ مساعد عرض `tasmeeErrorKindOf(key)`.

## 3) الألوان في `TasmeeStyle`

إضافة `tajweedErrorColor` (بنفسجي ‎#7E57C2 داكن/‎#6A1B9A فاتح)، `normalErrorColor` (أحمر = قيم incorrectColor الحالية)، `tashkeelErrorColor` (برتقالي ‎#FFB74D داكن/‎#EF6C00 فاتح) — و`correctColor` موجود أصلًا (أخضر). جميعها بـ defaults في المصنع القياسي.

## 4) العرض (مسارا QPC)

- **`custom_span.dart`**: مساعد `tasmeeErrorKindOfSegment` (نمط `tasmeeStatusOfSegment` نفسه: التسجيل، وضع العين، وصفحة النطاق فقط)؛ معامل جديد `Color? tasmeeUnderlineColor` على `_qpcV4SpanSegment` يُطبَّق على نص الحروف فقط: `decoration: underline, decorationColor: …, decorationThickness: 2` — الكلمة المخفية والجارية بلا خط (الجارية تحتفظ بتظليلها البرتقالي المرسوم القائم).
- **`rich_text_build.dart` + `qpc_v4_flowing_text.dart`**: حساب اللون لكل مقطع (حالة + نوع + `TasmeeStyle` بنمط كتلة hiddenColor الحالية) وتمريره؛ وإضافة خريطة الأنواع إلى `tasmeeFingerprint` كي يعاد البناء لحظة وصول كل حكم.
- **اتساق النتائج**: رقائق وبطاقات `tasmee_result_sheet.dart` تستخدم ألوان الأنواع الجديدة نفسها بدل accent/أحمر العام.

## 5) الاختبارات

- تحديث اختبارات النطاق الحالية لتوقيع `kind` الجديد.
- اختبارات جديدة في `quran_reference_range_test.dart`: فرق حركة (نفس الحرف رمز مختلف) → `tashkeel`؛ فرق مدّ → `tajweed`؛ وحدة عادية متخطَّاة → `normal`؛ مطابقة تامة → `correct`.
